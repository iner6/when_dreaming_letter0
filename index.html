GitHub Pages 部署说明
  1. 将全部文件上传到仓库根目录。
  2. 打开仓库 Settings → Pages。
  3. 在 Build and deployment 中选择 Deploy from a branch。
  4. 选择 main 分支与 /(root)，保存后等待发布。
  5. 打开发布页面，新增一封测试来信并刷新，确认 IndexedDB 可正常保存。
